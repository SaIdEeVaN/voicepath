# Deployment dependencies -- what fits a 512MB free container tier.
#
# The difference from requirements-ml.txt is torch, and it is the whole point:
#
#   torch + transformers      642MB    dropped
#   ctranslate2 + whisper      64MB    dropped (STT_PROVIDER=groq)
#   piper + onnxruntime + voices  273MB  kept
#   sentencepiece + e5-small  ~130MB  added 2026-11-10 (weights mapped, below)
#
# What that costs, and how it is paid:
#
#   Embeddings  EMBEDDING_PROVIDER=onnx runs multilingual-e5-small in the API
#               itself, through the onnxruntime Piper already needs. Until
#               2026-11-04 this was e5-base through the Hugging Face Inference
#               API, which then ran out of credits.
#   Memory      A voice is ~105 MB resident once it has spoken, e5-small ~250
#               MB, and the 512 MB container holds the embedder plus ONE
#               voice (~430 MB). Render killed it (oomKilled) at 11:50-11:52
#               and again at 12:33 on 2026-11-10. The build moves each model's
#               weights into a file the server maps (scripts/map_weights.py,
#               which is what `onnx` below is for) -- that avoids holding
#               every weight twice while loading, and it halves the heap, but
#               Render counts mapped pages once they are touched, so it is not
#               what makes it fit. What does: TTS_MAX_RESIDENT_VOICES=1.
#   Speech      STT_PROVIDER=groq. Already the default; the local Whisper path
#               was 32.5s on a 5.8s clip on a CPU and unusable anyway.
#
# Text-to-speech stays local: Piper is ONNX, not torch, and voices load lazily
# per language. If the container still runs out of memory, TTS_PROVIDER=offline
# hands synthesis to the browser and frees the last ~270MB.
#
# The model files are not packages: scripts/fetch_embedding_model.py fetches
# them at build time (via fetch_voices, which the build command runs).

-r requirements.txt

# Text to speech -- Piper, MIT. Bundles espeak-ng data, so no system package.
piper-tts==1.8.0

# Embeddings -- multilingual-e5-small on onnxruntime (the same range Piper
# asks for), tokenised by sentencepiece. Apache-2.0 and MIT.
onnxruntime>=1,<2
sentencepiece==0.2.2

# Build time only: scripts/map_weights.py moves each model's weights to a file
# the server maps instead of loading. The running API never imports it.
onnx==1.23.2
